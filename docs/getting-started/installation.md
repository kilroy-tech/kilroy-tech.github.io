# Download and Install Kilroy

## Platform Requirements

Kilroy is a cross-platform desktop application. Native desktop builds are supported on:

- macOS on Apple Silicon
- Windows 11
- Linux (Ubuntu and Debian)
- Docker on Apple Silicon, AMD/Intel, and ARM7 systems (including Raspberry Pi devices)

## Installation

Kilroy is distributed as a .zip file, .dmg disk image, or a .exe installer, depending on your O/S platform.

### macOS

Double-click the Kilroy disk image file, and in the open window, drag the Kilroy application to your Applications folder.

### Windows

If Kilroy was downloaded as a .zip file, unarchive it and run the resulting installer application. If it was downloaded as a .exe file, run the
installer directly.
After installation, continue to the [Quick Start](quick-start.md) to learn the Kilroy interface and get started with apps and groups.

For container deployments, see [Docker Installation](docker-installation.md).
